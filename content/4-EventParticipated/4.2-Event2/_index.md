# Event 2 Report: AWS Hackathon & Amazon Q Developer

## Summary

During my internship, I attended an AWS knowledge-sharing session focusing on **AWS Hackathon** and **Amazon Q Developer**. The session introduced the purpose of AWS Hackathon, how participants collaborate to solve real-world problems using AWS services, and how AI-powered development tools such as Amazon Q Developer can improve the software development process.

The speakers also shared practical experiences from previous hackathons, including project planning, teamwork, time management, and solution presentation. The session inspired me to explore cloud technologies further and encouraged me to participate in future hackathon events.

## Speakers

- **AWS/FCAJ Knowledge Sharing Team**

## What I learned

- Learned about the objectives and workflow of an AWS Hackathon.
- Understood how to transform an idea into a working cloud solution within a limited timeframe.
- Explored how Amazon Q Developer assists developers by generating code suggestions, explaining source code, and providing AWS best-practice recommendations.
- Learned the importance of selecting the appropriate AWS architecture to build scalable and reliable applications.
- Recognized that teamwork, communication, and presentation skills are just as important as technical knowledge during a hackathon.

## Why it mattered

- The session demonstrated how cloud technologies can be applied to solve practical business challenges.
- Hackathons provide an excellent opportunity to strengthen problem-solving skills while working under time constraints.
- AI tools such as Amazon Q Developer can significantly improve developer productivity, allowing teams to focus more on innovation and solution design.

## Takeaways for the team

- Continuously improve AWS knowledge and hands-on experience.
- Make effective use of AI-powered development tools while validating their suggestions.
- Strengthen teamwork and communication skills to improve project collaboration.
- Be open to learning new technologies and applying them in real-world projects.

## Personal reflection

This knowledge-sharing session gave me a better understanding of how AWS Hackathons help developers improve both technical and soft skills. I realized that a successful project requires not only technical expertise but also effective teamwork, proper planning, and clear communication.

I was particularly impressed by the demonstration of Amazon Q Developer. It showed how AI can accelerate software development by assisting with coding, debugging, and learning AWS services. However, I also learned that developers should always review AI-generated suggestions carefully before applying them to production projects.

## Thank you

I would like to express my sincere gratitude to the AWS/FCAJ team and the speakers for organizing this informative session. Their practical experiences and valuable insights motivated me to continue learning AWS technologies and to participate in future hackathons to enhance my technical skills.

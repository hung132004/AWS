I created a **Cognito User Pool** to store user accounts and manage authentication for the system.

#### Implementation steps

1. Open Amazon Cognito and create a new User Pool.
2. Configure email-based sign-in.
3. Set password policy and required user attributes.
4. Review the User Pool after creation.

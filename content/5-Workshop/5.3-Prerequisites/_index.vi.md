Trước khi triển khai hệ thống, tôi chuẩn bị mã nguồn frontend, tài khoản AWS, repository GitHub và các quyền cần thiết để tạo tài nguyên trên AWS.

#### Các thành phần cần có

- Source code của **Campus IT Support Ticket Portal**.
- Repository GitHub để kết nối với AWS Amplify Hosting.
- AWS account dùng để tạo Amplify, Cognito, API Gateway, Lambda, DynamoDB, S3, SES, CloudWatch và IAM.
- Region triển khai thống nhất cho các dịch vụ backend.
- Tài khoản email dùng để kiểm thử thông báo qua Amazon SES.

#### Kết quả

Sau bước chuẩn bị, project đã sẵn sàng để triển khai frontend lên AWS Amplify và cấu hình các dịch vụ backend serverless.
